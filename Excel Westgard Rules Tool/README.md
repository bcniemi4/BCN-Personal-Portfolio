Excel Westgard Quality Control Tools

This repository contains a growing collection of Microsoft Excel tools designed to automate quality control (QC) review using Westgard Rules and other laboratory data analysis techniques.

These tools were developed to improve the efficiency, consistency, and reproducibility of laboratory QC review by reducing manual calculations and providing clear visualizations of quality control performance.
